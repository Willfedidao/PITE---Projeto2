Projeto acadêmico de Engenharia de Software da Universidade Cruzeiro do Sul.
Objetivo: planejar e modelar um aplicativo de vendas online de cupcakes gourmet.
Funcionalidades: cadastro, catálogo, carrinho, pagamentos, pedidos e entregas.
Metodologias: UML, levantamento de requisitos, histórias de usuário e backlog.
